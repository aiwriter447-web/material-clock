💫 A Fresh Take on Time

Material Clock is a functional native Android application inspired by Google's Material 3 Expressive research concepts.

More than a UI mockup, it's a real application built with Jetpack Compose, combining expressive typography, thoughtful layouts, and modern Android development.

The design draws inspiration from Google's 46-study design program, specifically its concept renders rather than the production Google Clock 8.8.

🚀 Features

Feature| Experience
⏰ Alarms| Expressive, gesture-friendly alarm management.
🌍 World Clock| Track time across different cities.
⏳ Timers| Clear, easy-to-read countdown interfaces.
⏱️ Stopwatch| A dedicated precision time-tracking interface.

🎨 Design Highlights

- Material 3 Expressive — A distinctive interface inspired by Google's research concepts.
- Expressive Typography — Custom variable-font integration.
- Modern UI — Declarative layouts built with Jetpack Compose.
- Native Android — Designed to build, install, and run as an Android application.
