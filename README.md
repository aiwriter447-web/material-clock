</p>✨ About

A functional, native Android clock inspired by Google's Material 3 Expressive research concepts. Unlike static mockups, this project is built to run on Android using Jetpack Compose.

The design draws inspiration from Google's 46-study design program, specifically its concept renders rather than the production Google Clock 8.8.

🚀 Features

- ⏰ Alarms — Expressive, gesture-friendly alarm management.
- 🌍 World Clock — Track time across different cities.
- ⏳ Timers — Clean countdown interfaces for everyday use.
- ⏱️ Stopwatch — A dedicated precision time-tracking interface.

🛠️ Tech Stack

- Kotlin — Android development.
- Jetpack Compose — 100% declarative UI.
- Material 3 Expressive — Modern styling, typography, and motion.
- Variable Fonts — Custom typography integration.
